# OrbitRooms

OrbitRooms es una aplicación gratuita y offline-first desarrollada en Flutter para la gestión de hostales.

La aplicación está enfocada en ayudar a pequeños hostales y negocios familiares a administrar:

- reservas
- habitaciones
- huéspedes
- disponibilidad
- check-in y check-out
- historial de reservas

Toda la información funciona localmente en el dispositivo, sin necesidad de internet ni suscripciones.

## Objetivo

OrbitRooms busca ofrecer una solución:

- gratuita
- moderna
- simple de usar
- accesible para pequeños negocios
- funcional incluso sin conexión a internet

Especialmente pensada para LATAM y pequeños hostales que no pueden costear software administrativo costoso.

## Características

- Arquitectura offline-first
- Persistencia local de datos
- Calendario de reservas
- Gestión de habitaciones
- Gestión de huéspedes
- Interfaz moderna y simple
- Sin dependencia de internet

## Ejecutar el proyecto

Clonar el repositorio:

```bash
git clone https://github.com/tu-usuario/orbit_rooms.git
```

Instalar dependencias:

```bash
flutter pub get
```

Ejecutar la aplicación:

```bash
flutter run
```
